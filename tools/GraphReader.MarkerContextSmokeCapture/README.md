# Marker context smoke capture

This is a separate, exploratory, no-classifier capture tool for exactly the two nonsealed synthetic training smoke rasters pinned in `capture-protocol.json`. It reuses the reviewed `GraphReader.MarkerBoundInputTrainCapture` model/license/runtime binding and the same production importer, raster decoder, candidate OCR adapter, V27 marker-center adapter, marker-input builder, and sampler. It does not consume the sibling post-capture truth, annotations, development inputs, private inputs, or sealed inputs.

The tool is built as the existing allowed friend assembly name, `GraphReader.RealAcceptance.Ocr`, in this isolated project output. `--preflight` authenticates the reviewed base binding, its license checks, the new source and assembly hashes, the smoke completion/identity/raster manifests, and the two PNG payloads. Preflight does not construct ONNX sessions or run inference. `--capture` refuses to proceed without a separately created review receipt whose digest is supplied by the caller and whose fields bind the exact preflight descriptor, protocol, and executable assembly. No such approval receipt is created here.

The marker-classifier model is absent from the base binding and the injected `NoClassification` adapter throws if invoked. The tool captures production-generated marker inputs and sampler tensors only; it does not run classifier inference, optimizer steps, or training. The experimental wide sample view is retained as a diagnostic input, not as evidence of classifier performance or production parity beyond the shared sampler implementation.

For a reviewed build, set `DOTNET_CLI_HOME`, `NUGET_PACKAGES`, `TEMP`, and `TMP` to project-local paths under `E:\Graph-auto-reader\tools`, then build with `dotnet build tools/GraphReader.MarkerContextSmokeCapture/GraphReader.MarkerContextSmokeCapture.csproj --configuration Release --verbosity minimal -m:1 -p:NuGetAudit=false -p:UseSharedCompilation=false`. Run `--self-test` for no-inference protocol and rejection checks. After the executable and source hashes are stable, `Prepare-CaptureBinding.ps1` can create the fresh project-local preflight descriptor; review that descriptor before any capture. Do not infer acceptance, training eligibility, or real-world accuracy from this smoke run.

Capture reports include process elapsed time and the process peak working set. These are coarse whole-process measurements that include loaded runtime/model memory; they are not isolated sampler memory or throughput benchmarks.
