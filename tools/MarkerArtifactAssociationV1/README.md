# Marker artifact association v1

This isolated Python utility is a train-split, review-only diagnostic. It accepts already authenticated source-pixel candidate and truth records, and returns aggregate status counts without case-level output. It never reads files or data itself.

Only typed `legend_symbol` artifact truths with per-glyph single-draw ablation evidence can be matched as `matched_artifact_review_only`. `produce_legend_symbol_visibility` generates the original fixed train scene in memory. `produce_v5_train_overlay_glyph_visibility` separately regenerates one fixed V5 full-corpus train recipe, including its deterministic in-plot overlay, and requires the produced PNG SHA to equal the bound captured source metadata. It suppresses exactly one unique legend-marker renderer call, then applies that pixel delta only after verifying it does not intersect the retained overlay. The association entrypoint accepts either the v1 `capture_manifest.json` or the v2 `capture_manifest_v2.json`; each exact manifest SHA and its producer/bundle identities are pinned in `association.py`. It rechecks source ID, dimensions, original PNG SHA, producer source, renderer bundle, font identity, and each artifact binding before matching, then recomputes rendered-plane SHA, scene/annotation/glyph identity, draw ID, ablated-plane bytes, and changed pixels. A caller that forges raster, proof, and binding consistently still fails the fixed manifest check. These pins provide in-package integrity, not an independent signature or attestation; review and external pinning remain necessary.

Matching uses the existing inclusive Euclidean 2-pixel rule jointly across positive marker truths and artifact truths. A proposal that collides with either side, has duplicate/ambiguous links, overlaps a generic overlay, is a symbol input, is not a detector candidate, or comes from incomplete capture cannot become an artifact match. Generic overlays retain suppression precedence. Connected and isolated legitimate markers remain positive review outcomes. Unmatched proposals remain unknown. Other semantic negatives, including arrows, ticks, endpoints, dividers, and absent annotations, are not admitted.

Every result reports zero negative training rows, zero trainable rows, `training_approved=false`, and zero optimizer steps. It does not adapt or register the existing corpus schema and has not been run against real truth. Synthetic-only tests:
