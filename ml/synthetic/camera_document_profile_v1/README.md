# Camera-document exploratory synthetic development family v1

This package is an isolated copy of the synthetic scene templates, renderer,
font resolver, and schema. Existing candidate and dataset evidence pins the
original `ml/synthetic/` source hashes, so this profile does not modify those
files. `snapshot_bindings.json` records the exact source hashes from which the
copies began.

The profile adds one family identity, `camera_document_dev`, mapped to the
generator's `validation` label for compatibility. That label does not create
an independent split: there are no separately defined train, validation, or
reserved families here. The family is exploratory, is not registered in a
dataset preset, and is not training- or sealed-evaluation eligible. Historical
independence and near-duplicate exclusion from prior benchmark visuals are
unproven.

The camera-document degradation is deterministic and combines a mild
perspective warp with reduced chroma, slight blur, and JPEG re-encoding. Only
the perspective warp changes geometry; the renderer records its transform and
updates annotations and marker masks. No hand-drawn family is generated by
this profile or its tests.

The profile references the local Noto Sans Regular font only when the font
bytes and accompanying license evidence match the hashes in
`snapshot_bindings.json`. The source is pinned to
[`NotoSans-Regular.ttf`](https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans/NotoSans-Regular.ttf)
and its [LICENSE](https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/LICENSE).
The verified font and accompanying license are included under `assets/`, so
this isolated package can resolve them from a fresh checkout without depending
on ignored artifact storage. Scene provenance records both asset hashes,
labels the generator code license separately from the unassessed rendered-
output license, and records the Pillow version.
Bitwise reproducibility across hosts is unverified. These records do not
constitute a broader distribution or licensing approval. The hashes and
source URLs are repository provenance, not independent signed approval.

Maintenance cost: when the shared generator fixes rendering or schema bugs,
this isolated snapshot must be reviewed and rebased manually. The source hash
bindings make stale copies detectable; they intentionally do not auto-import
changes from the shared module.
