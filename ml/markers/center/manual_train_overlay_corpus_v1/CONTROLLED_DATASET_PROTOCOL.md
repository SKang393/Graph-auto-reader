# Native-parity controlled marker dataset

Materialize only the controlled overlay patches selected by the frozen
proposal-domain capture and verified byte-for-byte against the native C#
sampler. Authenticate the input manifest, overlay receipt, capture, Python
selection, parity result, and source before writing. Recompute every patch hash
from its captured three-plane frame and require a matching per-panel parity
count. Keep the 52 images without emitted proposals and all failures in the
receipt rather than inventing model inputs for them.

Assign labels solely from the injected marker or injected distractor inside
the opaque controlled patch. Never infer a negative label from unmarked native
image content. Preserve the frozen study-plus-image grouped internal build and
holdout partitions; reject any group overlap, repeated proposal identity,
unknown controlled label, hash mismatch, invalid float, or output overwrite.
Store tensors, group identifiers, image identifiers, coordinates, and receipts
only in ignored project-local artifacts.

This materialization performs no model training, model selection, development
or sealed payload reads, or release approval. The 20 groups and repeated
artificial shapes are exploratory. Any optimizer run needs a separately fixed
bounded recipe and evaluation and must use the RX 6600 XT without CPU fallback.
