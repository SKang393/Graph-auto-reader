# Owned OCR workspace prefix measurement

The previously identified synchronous copy/hash before
`ReadCalibrationLabelsAsync` returns was measured once. **No runtime change is
justified by this sample.** This is a workspace-prefix diagnostic, not an OCR,
automatic-calibration or interactive UI benchmark.

An isolated STA helper referenced the existing frozen Debug App output, without
rebuilding or copying App/test/probe assemblies. It linked the existing
`CpuBudgetJob` and verified BelowNormal priority, rate 416 on 12 logical CPUs,
and a 0.4992-logical-core cap. A zero-copy OCR stub returned a pending task and
started no inference child. Import, PNG generation, fake axis setup, state
hashing and cancellation were outside the timed call-to-Task-return interval.

Owned inputs used WPF Gray8 PNG encoding at 96 DPI: a white 160 by 120 control
and 4096 by 4096 pixels generated by xorshift32 (seed 393, shifts 13/17/5,
each low byte retained). The fake geometry was (left 8, bottom 110, right 155,
top 5), confidence 0.8; it was supplied for setup, not detected. The large input
is deterministic noise, not a graph accuracy fixture.
