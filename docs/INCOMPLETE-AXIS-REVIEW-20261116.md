# Review choices from an incomplete axis search

## Defect and bounded change

The [existing fixed development trace](NATIVE-AFFINE-AXIS-REVIEW-20261115.md)
had three pair-budget refusals among twelve geometry cases. Previous exact-pruning investigations did not establish a safe
way to finish these searches within the existing bounds. This change does not
claim to resolve automatic geometry or improve those twelve cases: no new
private comparison is authorized or performed by this batch.

Explicit **Review axis choices** can retain already-admitted geometry when a
later C# pair/envelope budget is exhausted. A separate optional observer carries
immutable original-pixel polygons and the exact budget reason, without a rank,
score, confidence or best-candidate claim. The ordinary detector still throws
its original refusal, and its complete ranked-candidate observer remains silent.
Cancellation and invalid input do not publish incomplete choices.

The review adapter applies its existing geometry, bounds, rounding, raster and
duplicate checks before exposing any choice. An explicit incomplete flag travels
through the transient worker response and source-bound workspace review. The
flag is bound to the review identity, and an explicitly selected suggestion
retains the warning reason. The UI warns before selection and afterward, leaves
selection empty, and keeps existing numeric validation and user review before
Apply. No scientific values are generated by choosing geometry.

Rust's protocol and automatic Suggest path are unchanged. Only the explicit
review path may use the existing OpenCV fallback after a valid empty Rust
`AMBIGUOUS_AXIS` response. It keeps both existing workers' time/resource bounds.
This can spend the fallback's existing bounded work after a Rust refusal; no
runtime speedup is claimed.

## Compatibility and validation scope

The project, vision-result and model-manifest JSON schemas are unchanged. The
new observer is opt-in. The private same-application review transport accepts
legacy complete responses when the new flag is absent, while rejecting unknown,
duplicate, malformed or inconsistent fields. No migration of saved projects is
needed. Persisted scientific output and automatic acceptance behavior are not
weakened.

Acceptance is structural: interrupted choices are individually validated and
visibly incomplete; no automatic winner, automatic selection or unreviewed
calibration is produced. Owned deterministic tests cover interrupted prefixes,
unchanged automatic refusal, cancellation/observer failures, wire validation,
snapshot identity, selection/refit guards and language notifications. No model
threshold or statistical acceptance bar changes. Train/dev/sealed identities
stay fixed, with **zero sealed reads** and no private input in these tests.
